my-winder turns my-* class names into inline styles at runtime — no build step, no stylesheet, no compiler.

See all demos → Get started
index.html
<!-- add classes → styles apply automatically --> <div class="my-dp-flex my-flex-col my-g-16 my-p-24 my-bg-111111 my-rounded-12 my-border-1-22c55e33"> <h2 class="my-f-24 my-fw-700 my-text-e8e8e8">Hello, my-winder 🍵</h2> <span class="my-bg-22c55e my-text-0a0a0a my-fw-700 my-rounded-999 my-pt-4 my-pb-4 my-pl-12 my-pr-12">zero config</span> </div>

Get started

Two ways in.

CDN / esm.sh

No install. Just a script tag.

Quickest
<!-- place before </body> --> <script type="module"> import { applyMyStyles } from "https://esm.sh/my-winder@1.1.7"; applyMyStyles(); </script>

Or auto-init with no function call:

<script type="module" src="https://esm.sh/my-winder@1.1.7/auto"></script>

npm

For bundled projects (Vite, Webpack, etc.)

# install npm install my-winder # import and call import { applyMyStyles } from "my-winder"; applyMyStyles(); # or auto side-effect import import "my-winder/auto";
